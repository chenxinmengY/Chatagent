# Chatagent 项目说明

Chatagent 是一个面向个人 AI 聊天的学习实践项目，使用 DSH 作为模型和插件执行后端，提供电脑网页、Windows 桌面窗口与 Android 客户端。开发过程中使用了 AI 编程工具辅助代码实现、调试和测试。

## 项目关注的问题

同一个角色在电脑和手机之间聊天时，需要保持消息、人格和会话身份一致。网络中断、程序重启或工具调用结果不明确时，也需要保存现有资料，并避免重复执行。插件能力需要按聊天授权，聊天记录和记忆还需要能迁移、核对和备份。

## 实现工作

- 设计客户端消息库、同步协议和待发状态，区分已保存、已执行、结果未知与已读；对未知操作只核对结果，不自动重放。
- 连接 DSH 专用会话，将客户端聊天、人格、工具权限和执行结果绑定到对应角色。
- 实现近期上下文窗口、话题摘要、历史检索及可配置的基础主动聊天行为。
- 实现资料导入、来源标识、预检、去重、附件校验和恢复流程。
- 完成 Android 聊天、录音和播放、通知与未读展示，以及 Windows 窗口和托盘交互。
- 通过合成数据、真实源代码测试与隔离接口测试检查状态恢复和协议兼容。

## 第三方与验证边界

DSH、语言模型、鱼记忆引擎、SenseVoice、CosyVoice 及相关推理和编解码组件来自第三方；版本、来源和分发边界见第三方说明。项目主要体现客户端、协议、资料管理和应用集成方面的探索。

自动化回归能够检查相应代码和协议行为；单次模型请求测试不能代表稳定延迟或记忆质量，电脑测试也不替代不同手机系统上的实机验收。项目仍在早期阶段，需要继续完善部署便利性、端到端验证和插件适配。

## 可用于介绍的简短描述

我在 AI 编程工具的辅助下，尝试实现了一个基于 DSH 的个人 AI 聊天客户端 Chatagent。它支持电脑与 Android 端聊天，重点练习了消息存储与同步、插件调用、上下文管理和历史资料迁移。项目使用现有模型和记忆插件，我主要围绕客户端交互、模块集成、异常恢复和测试进行学习与实践。
