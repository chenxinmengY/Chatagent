初次见面

装好了，再连上 DSH 就能聊天

电脑程序已经准备好。模型账号在 DSH 里设置，旧资料以后再搬也可以。

  1. 1

    复制一句配置要求

    在 Windows 右下角找到鲸鱼托盘图标（可能藏在小箭头里）。右键 → 复制首次连接提示词。

  2. 2

    交给电脑上的 DSH 或 Codex

    粘贴刚复制的内容，让它按你电脑的情况配置。需要模型账号时，在 DSH 里填写。

    完成后，它会告诉你连接配置 JSON 文件的位置。

  3. 3

    选好文件，开始聊天

    再次右键鲸鱼图标 → 导入 DSH 连接配置，选择它准备好的 JSON 文件。

    连接成功后进入软件，发送一句「你好」，确认收到真实回复。
