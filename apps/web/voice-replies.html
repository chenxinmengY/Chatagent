进阶，想用时再学

换成指定的声音说话
  1. 准备一段清楚的单人录音，以及录音里的原话。
  2. 在 AI 语音引擎中生成新的音色副本，接到当前聊天，再在语音页恢复 AI 音色。
  3. 回聊天请求一条短语音，听到新声音再使用。

使用自己录制或明确授权的声音。当前需要电脑端配置。一步步看图操作 → · 复制给 Agent 配置 →

让她唱歌、换唱歌音色
  1. 准备匹配唱歌引擎的 RVC 音色模型，有配套索引时一并保留。
  2. 在独立唱歌环境加载模型，试唱一小段。
  3. 接到当前聊天，开启唱歌工具，再核对收到的声音。

唱歌单独配置。一步步看图操作 → · 复制给 Agent 配置 →

A 卡 / N 卡：用显卡加快生成
  1. 打开任务管理器的“性能 → GPU”，看显卡名字。
  2. A 卡（AMD）：先验证匹配的 HIP 说话引擎；唱歌使用单独的 DirectML 环境。
  3. N 卡（NVIDIA）：当前应用尚无通用 CUDA 接入，先用基础语音。
