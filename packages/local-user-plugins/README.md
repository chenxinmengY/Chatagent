# Optional local plugin source

Code-only adaptations from [sourcepro5/WeChatAgent](https://github.com/sourcepro5/WeChatAgent) and the owner's earlier Cyberwife integration. See `SOURCE.json`, `WeChatAgent-LICENSE` and `components/qq-bridge/LICENSE`. `local-extension` means absent from the referenced public snapshot; it is not a claim that underlying algorithms or external services were authored here.

Changes include Chatagent session binding, copied plugin scope, read-only timetable context, reminder context isolation and delivery receipts, media recovery, and configurable host paths. Runtime state, credentials, accounts, courses, persona and media assets are excluded. Follow `docs/LOCAL-PLUGINS.md` from the repository root.
